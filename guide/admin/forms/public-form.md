# 공개 폼 — 응답자가 보는 화면

**주소** `/f/{키}` · 로그인 없이 접근 가능

운영진이 만든 폼의 **공개 링크**를 응답자에게 공유하면, 응답자는 이 화면에서 어드민 로그인 없이 작성합니다. 다만 회원 식별이 필요한 폼은 응답자에게도 Google 로그인을 요구할 수 있습니다.

> **화면 예시** 공개 폼 작성 화면 — `/f/{키}`
>
> - 맨 위 동아리 마크와 «SSCC»
> - 폼 제목 «2026 신입회원 모집», 접수 기간 «08.01 09:00 \~ 08.25 23:59», 진행 막대
> - 문항 카드 «이름을 입력해 주세요 \*»와 입력칸
> - 오른쪽 아래 버튼 **다음**

마지막 페이지까지 마치고 제출하면 완료 화면으로 넘어가며, 이후에는 같은 링크로 다시 들어가도 재작성할 수 없습니다(폼이 재제출을 허용하지 않는 한).

## 공개 링크 주소가 바뀌었습니다

폼 상세의 **링크 복사**로 만들어지는 주소가 **숫자에서 임의의 키**로 바뀌었습니다 — `/f/12` 대신 `/f/3f9a…` 모양입니다. 주소만 보고 다른 폼을 찾아 들어갈 수 없게 한 것입니다.

:::note[참고]

**예전에 공유한 숫자 주소도 그대로 열립니다.** 이미 공지나 메신저로 보낸 링크를 다시 보내지 않아도 됩니다 — 새로 복사하는 링크만 새 모양으로 나갑니다.

:::

## 메신저에 붙이면 그림 카드로 보입니다

공개 폼 링크를 카카오톡·디스코드에 붙여 넣으면 글자만 있던 미리보기가 **제목과 안내가 적힌 큰 그림**으로 바뀝니다. 운영진이 따로 만들 것은 없습니다 — 링크를 붙이는 순간 그 폼의 제목으로 그려집니다.

> **화면 예시** 메신저에 뜨는 공유 카드 — 링크를 붙이는 순간 그려집니다
>
> - 짙은 남색 바탕 그림 위쪽에 동아리 마크와 «SSCC 숭실컴퓨팅클럽»
> - 가운데 큰 글씨로 폼 제목 «2026 신입회원 모집», 그 아래 안내 «숭실컴퓨팅클럽 2026학년도 신입회원을 모집합니다»
> - 아래쪽 작은 글씨 «신청서 · 로그인하면 바로 작성할 수 있습니다»
> - 그림 밑에 링크 주소(예: sscc.example.com/f/3f9a…)

| 카드에 담기는 것 | 어디서 오나 |
|---|---|
| 제목 | 폼 제목입니다. 너무 길면 뒤가 «…»로 잘립니다. |
| 안내 문구 | 폼 편집기의 안내 문구 앞부분입니다. 비어 있으면 «숭실컴퓨팅클럽(SSCC) 신청서입니다»가 대신 들어갑니다. |
| 동아리 마크 | 탭·홈 화면 아이콘과 같은 그림입니다. |

:::note[주의]

**접수 상태와 마감일은 카드에 넣지 않습니다.** 메신저는 한 번 만든 카드 그림을 다시 그리지 않습니다 — 넣어 두면 접수가 끝난 뒤에도 «모집 중»이라고 적힌 그림이 대화방에 그대로 남습니다. 마감을 알리려면 카드가 아니라 공지로 알려주세요.

:::

카드 모양이 예전 그대로라면 메신저가 옛 미리보기를 기억하고 있는 것입니다. 대화방에 이미 뿌린 링크는 바뀌지 않습니다 — 새로 붙이는 링크부터 그림 카드로 보입니다.

## 낸 사람은 자기 응답을 다시 볼 수 있습니다

예전에는 운영진이 **수정 요청**을 보내야만 신청자가 자기 응답을 열 수 있었지만, 이제 **제출·승인·반려 어느 상태든 열립니다**. «내 신청»의 **제출 내용 보기**로 들어가며, 반려된 응답도 사유를 확인할 수 있습니다. **다시 낼 수 있는 것은 여전히 수정 요청을 받은 응답뿐**입니다 — 나머지는 읽기만 됩니다.

## 기획안 링크로 들어오면 학술 앱으로 넘어갑니다

**기획안 폼의 옛 공개 링크**(`/f/…`)로 들어오면 이제 문항이 그려지지 않습니다. **«기획안은 LMS에서 냅니다»** 안내가 뜨고 **학술 앱 제출 화면으로 바로 넘어갑니다**([기획안 제출 · 재제출](../../lms/proposals.md)).

| 보이는 것 | 왜 |
|---|---|
| «기획안은 LMS에서 냅니다» 카드 | 기획안 작성에는 커리큘럼 쓰는 법 같은 안내가 필요한데, 이 화면은 아무 폼이나 그리는 일반 응답 화면입니다 |
| «LMS에서 기획안 제출하기» 버튼 | 자동 이동이 막히는 브라우저가 있어 직접 누를 것을 함께 둡니다 |

:::note[참고]

**이미 나눠 준 링크를 회수하지 않아도 됩니다.** 어드민에서 공개 링크를 닫았지만([시스템 폼 목록](system-forms.md)) 복사돼 돌아다니는 링크는 살아 있습니다 — **막는 대신 제자리로 보냅니다.** 응답이 엉뚱한 곳에 쌓이지 않습니다.

:::

학술 앱 주소가 설정되지 않은 환경에서는 이동도 버튼도 없이 안내만 뜹니다 — «운영진에게 문의해주세요»가 함께 나옵니다.

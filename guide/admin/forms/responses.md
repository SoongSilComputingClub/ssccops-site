# 응답 확인

**주소** `/forms/{id}/responses` · `/forms/{id}/responses/{rid}`

제출된 응답을 확인하고, 필요하면 승인하거나 반려합니다.

> **화면 예시** 응답 목록 — `/forms/{id}/responses` (상태 클릭 시 변경 창)
>
> - 위쪽 칩: «전체 · 제출 · 승인 · 반려», 점선 칩 «작성중»
> - 열: 이름 · 학번 · 학과·등급·상태 · 제출일시 · 상태
> - 예: «전기공학부 · 신입 · 활동 · 08.14 21:03 · 승인», «산업정보시스템 · 신입 · 활동 · 08.15 10:41 · 반려»

응답 상세 화면 하단의 **이전 · 다음** 버튼으로 목록을 다시 열지 않고도 연속으로 검토할 수 있습니다.

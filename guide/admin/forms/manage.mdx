# 폼 관리 · 편집기

**주소** `/forms` · `/forms/{id}` · `/forms/{id}/edit`

신입회원 모집, 행사 참가 신청 같은 **외부 공개 설문**을 만듭니다. 여러 페이지로 나눌 수 있고, 선택지에 따라 다음 페이지를 다르게 보여주는 분기도 지원합니다. 작성 중인 내용은 자동으로 저장됩니다.

<FormListMock />

## 편집기 — 페이지와 문항 구성

<FormEditorMock />

| 문항 유형 | 비고 |
|---|---|
| 단답형 · 장문형 | 텍스트 입력. 정규식으로 입력 형식을 검증할 수 있습니다(고급 설정). |
| 단일 선택 · 다중 선택 | 선택지별로 다음에 어느 페이지로 보낼지 분기를 지정할 수 있습니다. |
| 날짜 | 날짜 선택 입력. |

:::note[참고]

화면 상단의 **저장 상태 표시줄**에서 저장 여부를 확인할 수 있습니다. 입력을 멈추면 자동으로 저장됩니다. 다른 화면으로 이동하기 전에는 표시줄이 "저장됨"으로 바뀌었는지 확인하세요.

:::

## 접수 상태 바꾸기

폼 상세 화면 하단에서 접수를 시작하거나 마감할 수 있습니다. 접수를 마감하면 공개 링크에 들어온 응답자는 더 이상 새 응답을 제출할 수 없고, 이미 제출된 응답은 그대로 남습니다.

:::note[참고]

**«접수 상태 변경»은 폼 편집과 다른 권한입니다**(FORM_STATUS_CHANGE). 문항은 고칠 수 있는데 접수 시작·마감만 잠겨 있다면 필요한 권한이 다른 것입니다. 학술 **모집** 폼은 여기서 접수를 시작할 수 없고 모집 관리 화면에서 시작합니다([모집 관리](../academic/recruitment.mdx)) — 다만 마감은 이 화면에서 합니다. 기획안 시스템 폼은 [기획안 접수 열기](../academic/proposal-intake.mdx)를 보세요.

:::

## 다중 응답 허용

편집기에서 **다중 응답 허용**을 켜면 «한 사람이 여러 건을 낼 수 있습니다» — 지원서·설문처럼 한 사람이 한 번만 내야 하는 폼은 꺼 둡니다.

:::note[참고]

**이미 응답이 들어온 뒤에도 바꿀 수 있습니다.** 끄면 «지금부터» 새 응답만 받지 않고, 이미 들어온 응답은 지워지지 않고 그대로 남습니다.

:::

## 템플릿 관리

**주소** `/forms/templates`

자주 쓰는 문항 구성을 **템플릿**으로 저장해 두고, 새 폼을 만들 때 골라 씁니다(예: «신규 부원 모집 표준 문항»). 어떤 폼에 쓰는 구성인지 설명을 적어 두면 고를 때 도움이 됩니다.

:::note[주의]

**사용 여부를 끈 템플릿은 폼을 만들 때 고를 수 없습니다** — 목록에는 남지만 «사용하지 않는 템플릿입니다»로 표시됩니다. 다시 쓰려면 사용 여부를 켜세요.

:::

## 접수 상태 칩 — 여러 개를 함께 켭니다

필터 칩과 카드 배지는 같은 상태명을 씁니다. 칩은 **전체 · 작성중 · 접수 예정 · 접수중 · 기간 종료 · 마감** 순입니다. v0.2.12부터 **칩을 체크박스처럼 여러 개 켤 수 있습니다** — 하나만 고르는 방식이 아닙니다. 누를 때마다 켜지고 꺼지며, **마지막 하나는 꺼지지 않습니다**(아무것도 안 켜진 목록은 뜻이 없기 때문입니다).

:::note[참고]

**처음 들어가면 «작성중 · 접수 예정 · 접수중» 셋이 켜져 있습니다**(v0.2.12에 바뀌었습니다 — 그전에는 «접수중» 하나였습니다). **지금 손대고 있는 폼**을 모아 보여 주는 시작점입니다. 끝난 폼까지 찾으려면 **전체** 칩을 누르세요.

:::

고른 칩은 **주소에 남습니다** — 뒤로 가기로 직전 필터가 되살아나고, 그 주소를 그대로 공유하면 상대도 같은 화면을 봅니다.

**기획안 폼은 이 목록에 없습니다**(v0.2.12). 시스템 폼은 목록 위 «시스템 폼» 버튼으로 따로 봅니다 — [시스템 폼 목록](system-forms.mdx).

## 폼 삭제 · 지운 폼 되살리기

**주소** `/forms/deleted`

폼 카드의 **삭제**로 지우고, 사이드바 **설정 › 폼 › 지운 폼**(또는 목록 위 «지운 폼» 버튼)에서 되살립니다. 응답이 있는 폼도 삭제할 수 있으며, 삭제된 동안에는 응답도 신청자 화면에 표시되지 않습니다.

| 동작 | 일어나는 일 |
|---|---|
| 삭제 | 목록에서 빠지고, **그 폼에 낸 응답은 신청자의 «내 신청»에서도 보이지 않게** 됩니다. 확인 창이 응답 건수를 먼저 알려줍니다. |
| 되살리기 | **접수 상태·라벨·응답이 지우기 전 그대로** 돌아옵니다. 되살릴 때는 확인 없이 바로 실행됩니다. |

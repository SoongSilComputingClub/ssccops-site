# CSV 회원 이관

**주소** `/members/csv-import`

과거 명단(엑셀·구글 시트를 CSV로 내보낸 파일)을 한 번에 등록하는 4단계 절차입니다. **중복으로 보이는 행은 자동으로 병합하지 않고 건너뜁니다.** 실행 결과는 되돌릴 수 없으므로 3단계 검증에서 반드시 내용을 확인하세요.

> **화면 예시** CSV 회원 이관 — 1단계 파일 선택
>
> - 위쪽 단계 표시: 1 파일 선택(현재) · 2 컬럼 매핑 · 3 사전 검증 · 4 결과
> - 점선 상자 안에 «CSV 파일을 여기로 끌어오거나», 버튼 **CSV 파일 선택**

> **화면 예시** 3단계 사전 검증 — 이 숫자를 반드시 확인하고 다음으로
>
> - 카드 넷: 전체 행 86 · 정상 후보 79 · 오류 3 · 중복 후보 4

1. **양식 CSV를 먼저 내려받아** 형식을 맞춘다\
   필수·조건부·선택 컬럼이 표로 안내됩니다.
2. 내 파일의 **헤더를 시스템 필드에 연결**한다\
   헤더명이 정확히 일치하지 않아도 직접 매핑할 수 있습니다.
3. **오류·중복 행을 확인**한다\
   이 행들은 이관되지 않고 건너뜁니다 — 실행 전 사유를 꼭 읽어보세요.
4. "되돌릴 수 없다는 것을 확인했습니다"에 **체크 후 실행**한다\
   실행하면 정상 후보만 새 회원으로 등록됩니다.

:::note[주의]

**명부의 «가입일»은 «동아리 가입 시기» 열에 넣으세요** (v0.2 · 양식 CSV도 함께 바뀌었습니다). **«전산 가입일»은 이관을 실행한 날로 시스템이 적는 값**이라 여기에 과거 날짜를 넣는 자리가 아닙니다 — 두 열을 바꿔 넣으면 모든 회원의 동아리 가입 시기가 이관일로 들어갑니다. **기수는 자동으로 채워지지 않습니다**(«학번으로도 동아리 가입 시기로도 자동 채우지 않습니다») — CSV에 기수 열을 직접 넣거나, 이관 뒤 회원 편집에서 채웁니다.

:::

이관된 회원은 아직 **로그인 계정과 연결되지 않은 상태**입니다(이름 옆에 "이관" 표시). 본인이 Google로 가입하면 그때 실제 계정과 연결됩니다 — 이관만으로 로그인이 가능해지는 것은 아닙니다.

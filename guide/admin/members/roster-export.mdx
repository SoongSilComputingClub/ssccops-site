# 회원명부 내보내기

**주소** `/members/roster-export`

학기마다 동아리연합회에 내는 **회원명부를 연합회 양식(xlsx) 그대로** 내려받습니다. 회원 목록을 보며 양식에 손으로 옮겨 적던 일을 대신합니다. 사이드바 **«설정 › 회원 › 회원명부 내보내기»**([CSV 회원 이관](csv-import.mdx) 바로 아래)이고, 권한도 CSV 회원 이관과 같습니다.

<RosterExportMock />

| 칸 | 무엇을 정하나 |
|---|---|
| 포함할 회원 상태 | 처음에는 **재학**만 골라져 있습니다. 이대로 내려받으면 연합회 제출용입니다. 동아리 안에서 쓸 명부가 필요하면 휴학, 졸업 등을 더 고릅니다. 하나도 고르지 않으면 내려받을 수 없습니다. |
| 직책 표기법 | 고를 것이 없습니다. 직책 칸은 언제나 **회장, 부회장, 정회원** 셋입니다. 연합회는 회장과 부회장 외에는 모두 «정회원»으로 받습니다. 회원 등급의 정회원과는 이름만 같아서, 준회원과 활동회원도 명부에서는 «정회원»입니다. |
| 명단 미리보기 | 고른 상태로 **몇 명이 오르고 몇 명이 왜 빠지는지**를 셉니다. 회원 목록의 인원과 명부 인원이 다를 때 여기서 이유를 봅니다. 명단은 **오늘** 기준 회원 상태와 역할로 만듭니다. |
| 파일 이름 | 연도와 학기는 **파일 이름과 시트 제목에만** 쓰입니다. 명단이 그 학기 기준으로 바뀌지는 않습니다. 제목 괄호는 고른 상태를 말합니다. 재학만이면 양식 그대로 «(재학생)», 더 고르면 «(재학·일반휴학)»처럼 적히고, 전부 고르면 괄호가 없습니다. |

1. **포함할 회원 상태를 고릅니다.**\
   연합회 제출이면 그대로 둡니다.
2. **명단 미리보기의 인원을 확인합니다.**\
   임시회원으로 빠진 사람이 실제 회원이면 [회원 상세](roster.mdx)에서 등급을 바꾼 뒤 다시 엽니다.
3. **연도와 학기를 고르고 «내려받기»를 누릅니다.**\
   연합회 원본 양식 그대로입니다. 단대와 학과 드롭다운, 서식이 살아 있고 회장, 부회장, 나머지(학번순) 순서로 채워집니다.

:::note[주의]

**회장이 없으면 내려받을 수 없습니다.** 오늘 기준으로 «회장» 역할이 배정된 회원이 없으면 미리보기에 «회장이 없어 내려받을 수 없습니다»가 뜨고 파일이 만들어지지 않습니다. [역할 관리](roles.mdx)에서 회장을 배정하고 다시 여세요. 회장은 역할 **이름**으로 찾으므로, 역할 이름을 «회장»에서 바꾸면 같은 문구가 뜹니다. 부회장은 없어도 내려받을 수 있습니다(부회장 줄 없이 나옵니다).

:::

:::note[참고]

**누가 언제 몇 명을 내려받았는지 기록이 남습니다.** 연락처와 학번이 담긴 명부가 밖으로 나가는 일이라 남기는 것이고, 회원의 이름과 연락처는 기록에 들어가지 않습니다. 학과명이 연합회 목록에 없는 회원은 단대 칸이 비어 있으니 제출 전에 한 번 보세요.

:::

회원명부는 AI 클라이언트 대화로 내려받을 수 없습니다. 연락처와 학번이 대화로 나가지 않게 이 화면에서만 받습니다.

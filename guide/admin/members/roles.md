# 역할 · 권한

**주소** `/members/roles` · `/members/roles/{id}/authorities` · `/members/authorities`

"회장", "국장", "박람회 총괄" 같은 **역할**을 만들고, 역할마다 어떤 **권한**을 줄지 정하는 화면입니다. 버튼과 메뉴는 회원에게 부여된 권한에 따라 표시됩니다.

> **화면 예시** 역할별 권한 부여 — 체크는 직접 부여, 파란 배지는 상위 권한에서 상속됨
>
> - 왼쪽 **역할별 권한 부여 — 회장**: 권한마다 체크칸 · 권한 이름 · 코드
>   - 업무 관리 `WORK_MANAGE` (체크)
>   - 회원 관리 `MEMBER_MANAGE` (체크, 오른쪽에 «상위에서 부여» 배지)
>   - 폼 라벨 관리 `FORM_LABEL_MANAGE` (빈칸)
> - 오른쪽 **변경분 요약**: «실제 부여 권한 5개 → 6개», «부여 SUB_WORK_TYPE_MANAGE», 버튼 **되돌리기** · **저장**

| 개념 | 의미 |
|---|---|
| 역할 | 회원에게 붙는 이름표. 한 회원이 역할을 여러 개 가질 수 있고, 그중 하나를 "대표" 역할로 지정할 수 있습니다. |
| 권한 | 화면 기능 하나하나에 매달린 코드(예: `WORK_MANAGE`). 역할에 권한을 체크해야 그 역할을 가진 회원이 해당 기능을 씁니다. |
| 상속 | 권한 트리에서 상위 권한을 가지면 하위 권한도 자동으로 포함됩니다. "상위에서 부여" 배지가 붙은 항목은 체크를 해제할 수 없습니다. |

:::note[주의]

**묶음 권한만으로는 세부 권한이 열리지 않습니다.** 예를 들어 어떤 역할에 "업무 쓰기" 권한만 주면 "업무 관리" 묶음 권한은 자동으로 따라오지 않습니다 — 화면은 정확히 그 회원이 가진 권한 코드만 보고 버튼을 그립니다.

:::

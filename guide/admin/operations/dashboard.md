# 운영 대시보드

**주소** `/dashboard` · 로그인 후 처음 보는 화면

대시보드에는 **내가 승인할 업무**, **곧 마감되는 업무**, **내가 담당한 업무**가 표시됩니다. 여기서 오늘 처리할 일을 확인할 수 있습니다.

> **화면 예시** 운영 대시보드 — `/dashboard`
>
> - 왼쪽 위 **승인 대기 목록** 카드: 오른쪽 위에 «전체보기», 열은 하위 업무명 · 요청자 · 마감_일시 · 하위_업무_유형. 예: «2026 신입회원 OT 예산 집행 · 8월 18일 · 예산지출»
> - 오른쪽 위 **다가오는 마감** 카드: 날짜 옆에 `D-DAY`(빨간 테두리) · `D-1` 배지와 업무 이름. 예: «8월 18일 D-DAY 신입회원 OT 예산 집행», «8월 19일 D-1 동아리 박람회 부스 기획»
> - 아래 **내 업무 목록** 카드: 제목 옆에 «전체 · 마감임박 · 지연» 칩과 건수(3건), 열은 하위 업무명 · 업무_상태 · 마감_일시 · 진행률. 예: «예산 집행 보고서 작성 · 검토 · 8월 18일 마감임박 · 100%», «부스 배치도 기획 · 기획 · 8월 19일 마감임박 · 0%»

| 영역 | 보여주는 것 |
|---|---|
| 승인 대기 목록 | 지금 나에게 승인 요청이 와 있는 하위 업무 미리보기. 행을 누르면 승인함으로 이동합니다. 이 카드는 `WORK_MANAGE` 권한이 있어야 보입니다. |
| 다가오는 마감 | 마감이 임박한 순서대로 나열됩니다. 배지는 `D-DAY`·`D-1` 식으로 남은 일수를 보여주며, 이미 지난 것은 빨간 테두리로 구분됩니다. |
| 내 업무 목록 | 담당자가 나인 하위 업무 전체. 상단 칩으로 전체·마감임박·지연만 골라볼 수 있습니다. |

## 배지의 뜻 — 지연 · 마감임박 · 승인 정체

대시보드의 각 행에는 마감 상태와 승인 상태를 나타내는 배지가 표시됩니다. **마감임박·지연**은 날짜를, **요청 전·승인 정체**는 승인 절차를 나타냅니다.

| 배지 | 붙는 기준 | 다음에 누가 |
|---|---|---|
| 마감임박 | 마감까지 3일 이내(오늘 포함) · 미완료 | 담당자가 마무리합니다. |
| 지연 | 마감일이 이미 지남 · 미완료 | 담당자가 마무리합니다. |
| 요청 전 | 완료 점검을 전부 체크했지만 **완료 승인 요청을 아직 누르지 않음** | **담당자**가 완료 승인 요청을 누릅니다. |
| 승인 정체 | 완료 승인 요청 후 **3일이 지나도록 승인·반려되지 않음** | **승인자**가 승인 또는 반려를 누릅니다. |

**승인 대기 목록에는 「승인 정체」만 표시됩니다.** 「요청 전」 상태는 아직 승인 요청을 하지 않았으므로 이 목록에 나오지 않습니다. 각 배지의 자세한 기준과 나머지 모든 상태 변화 규칙은 [상태 변화 기준](../../reference/status-rules.md)에 모여 있습니다.

:::note[참고]

업무를 새로 만들 권한이 있으면 화면 오른쪽 위 **+ 등록** 버튼이 활성 상태로 보입니다. 권한이 없으면 버튼은 그대로 있지만 눌러도 반응하지 않고, 위에 마우스를 올리면 이유가 말풍선으로 뜹니다.

:::

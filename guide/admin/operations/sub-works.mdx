# 하위 업무

**주소** `/operations/sub-works` · `/operations/sub-works/{id}` · `/operations/sub-works/{id}/edit`

하위 업무는 담당자가 직접 처리하는 업무 단위입니다. **기획 → 진행 → 검토 → 완료** 순서로 진행하며, 유형에 따라 완료 전에 승인이 필요합니다.

## 단계별 버튼

| 현재 단계 | 보이는 버튼 | 다음 단계 |
|---|---|---|
| 기획 | 착수 | 진행 |
| 진행 | 완료 승인 요청 | 검토 |
| 검토 | 완료 승인 / 반려 | 완료 / 진행(반려 시) |

:::note[참고]

**승인 버튼과 완료 점검은 서로 다른 조건입니다.** 승인 버튼이 보이는 것은 "권한이 있다"는 뜻일 뿐이고, 실제로 눌러 완료 처리하려면 오른쪽 완료 점검 목록이 전부 체크돼 있어야 합니다(정족수가 있는 유형은 정족수도 함께 채워야 합니다). 체크가 덜 됐는데 버튼이 잠겨 있다면 권한 문제가 아니라 점검 미완료입니다.

:::

## 완료 점검 항목 편집

완료 점검 목록은 유형에 따라 등록 시점에 자동으로 만들어지지만, 이제 **그 자리에서 항목을 더하고 문구를 고치고 지울 수 있습니다**. 목록 오른쪽 위 **항목 편집** 버튼을 누르면 편집 모드가 열립니다.

| 잠겨 있다면 | 이유 | 푸는 방법 |
|---|---|---|
| 항목 편집 버튼이 잠김 | 권한이 없습니다 | 담당자 본인이거나 업무 관리(WORK_MANAGE) 권한이 있어야 합니다. |
| 항목 편집 버튼이 잠김 | 지금 단계에서는 항목을 바꿀 수 없습니다 | 상태를 되돌릴 수 있는 사람이 이전 단계로 돌려야 합니다. |
| 특정 항목만 삭제 버튼이 없음 | **이미 체크된 항목**입니다 | **체크를 해제하면** 삭제 버튼이 나타납니다 — 본인이 바로 풀 수 있습니다. |

체크된 항목에는 삭제 버튼이 표시되지 않습니다. 삭제하려면 먼저 체크를 해제하세요. 버튼이 표시되지 않는 이유는 목록 아래에서 확인할 수 있습니다.

## 첨부 파일

업무 · 하위 업무 · 회의 상세 아래에 **«첨부»** 절이 생겼습니다. 견적서·계획서·발표 자료처럼 **그 건에 딸린 파일**을 올려 둡니다. 세 화면 모두 같은 모양입니다.

<AttachmentMock />

| 할 일 | 어떻게 |
|---|---|
| **올리기** | «+ 파일 올리기»를 누르고 파일을 고릅니다. 한 번에 한 개씩입니다. |
| **내려받기** | **파일 이름을 누릅니다.** 화면을 벗어나지 않고 저장 창만 뜹니다. |
| **지우기** | 줄 오른쪽 «지우기». **되돌릴 수 없습니다.** |

:::note[주의]

**25MB까지, 문서·표·발표·압축·이미지만 올라갑니다.** 큰 파일이나 동영상은 올라가지 않습니다 — **결과물 링크는 «추가 정보»의 «외부 URL»에** 적으세요. 형식이 맞지 않으면 «첨부할 수 없는 형식입니다», 크기를 넘기면 «파일이 25MB를 넘습니다»가 뜹니다.

:::

**내려받기는 그 건을 볼 수 있으면 누구나** 할 수 있습니다. **올리기와 지우기는 그 건을 고칠 수 있는 사람**만 — 담당자 본인이거나 업무 관리 권한이 있어야 합니다. 권한이 없으면 «+ 파일 올리기»가 잠기고 버튼에 사유가 붙습니다.

## 외부 URL

하위 업무 상세의 **«추가 정보»** 표에 **외부 URL** 줄이 생겼습니다. 결과물이 있는 곳(공유 문서·디자인 파일·저장소)을 적어 두는 자리입니다. 비어 있으면 «-»로 보입니다.

## 점검 목록 변경 이력

완료 점검 항목을 고칠 수 있게 된 대신, **누가 무엇을 바꿨는지 남습니다.** 상세 아래 «점검 목록 변경 이력» 절의 «**보기**»를 누르면 펼쳐집니다(평소에는 접혀 있습니다).

| 표시 | 뜻 |
|---|---|
| 추가 | 항목을 새로 넣었습니다 — «후»만 보입니다 |
| 수정 | 문구를 고쳤습니다 — «전»과 «후»가 나란히 보입니다 |
| 삭제 | 항목을 뺐습니다 — 지운 문구에 줄이 그어집니다 |

각 줄에 **바꾼 사람과 시각**이 함께 적힙니다. **진행 단계에서 항목 편집을 열면** «착수 뒤 수정입니다 — 이력에 남습니다» 안내가 먼저 뜹니다.

## 하위 업무 수정에서 바꿀 수 없는 것

**하위 업무 유형과 상위 업무**는 등록 시점에 고정됩니다. 유형에는 승인 필요 여부·승인자·정족수·완료 점검 항목이 연결돼 있어 나중에 바꿀 수 없습니다. 유형을 잘못 골랐다면 해당 하위 업무를 마감하고 새로 등록해야 합니다.

**담당자는 v0.2.8부터 바꿀 수 있습니다** — 하위 업무 수정 화면에서 다른 회원을 고르면 됩니다. 업무와 달리 **활동 중인 회원이면 국원도 후보**에 오릅니다([업무](works.mdx#담당자-넘기기)의 «담당자 넘기기» 참고).

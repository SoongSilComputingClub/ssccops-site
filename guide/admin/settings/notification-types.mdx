# 알림 유형 — 어느 앱에 보일지 정하기

**주소** `/settings/notification-types` · **메뉴** 사이드바 설정 › 통합 › 알림 유형 · 최고관리자만

알림 종류마다 **그 알림이 어느 앱에 보일지**를 정합니다. 전에는 이것이 코드에 박혀 있어 바꾸려면 배포를 해야 했습니다. 이제 이 화면에서 바꾸면 **바로 반영**됩니다.

:::note[주의]

**최고관리자에게만 보입니다.** 권한이 없으면 사이드바에 «알림 유형»이 뜨지 않습니다 — [전체 메뉴](navigation.mdx#전체-메뉴--이-앱의-모든-화면)에서는 잠금으로 보입니다. 알림이 어느 앱에 속하는지는 학기마다 앱 구성이 바뀌면 함께 바뀌는 시스템 설정이라 위임 대상을 두지 않았습니다.

:::

## 처음 상태

| 보이는 앱 | 알림 종류 |
|---|---|
| 운영(admin) | 승인 요청 · 승인 · 반려 · 마감 D-1 · 마감 지남 — 하위 업무를 다루는 사람에게 갑니다 |
| 홈페이지(www) | 응답 승인 · 응답 반려 · 응답 수정 요청 · 참가 확정 · 참가 대기 · 참가 취소 — 폼을 내거나 행사를 신청한 회원에게 갑니다 |
| 정하지 않음 | 테스트 — 누른 앱에만 뜹니다 |

## «보낸 앱 따름으로»를 누르면

그 줄의 설정이 **지워지고 정하지 않은 상태로 되돌아갑니다.** 정하지 않은 유형은 **그 알림을 만든 앱에만** 보입니다 — 학술 앱에서 생긴 일은 학술 앱에, 운영관리에서 생긴 일은 운영관리에. 잘못 바꿨을 때 되돌리는 버튼이자, «따로 정할 필요 없음»을 뜻하는 상태이기도 합니다.

:::note[참고]

**한 유형을 여러 앱에 켤 수 있습니다.** 셋 다 켜면 같은 알림이 세 앱 모두에 뜹니다. 회원이 주로 쓰는 앱이 갈릴 때 씁니다.

:::

여기서 정한 것이 회원 화면에서 어떻게 보이는지는 [알림 · 푸시](../../account/notifications.md)에 있습니다.

# 학술 대시보드 · 회차 이력 · 출석 통계

**주소** `/academic-programs/dashboard` · `/academic-programs/sessions` · `/academic-programs/attendance`

학술국장이 전체 활동을 확인하는 세 화면입니다. **대시보드**에서는 지연되거나 폐지된 프로그램과 승인 대기를, **회차 이력**에서는 활동별 회차 진행 상황을, **출석 통계**에서는 회원별 출석률을 확인합니다.

<AcademicDashboardMock />

:::note[참고]

**«이번 주 회차»는 진행일 기준입니다.** 아직 진행하지 않은 예정 회차는 여기 들어오지 않습니다 — 목록이 진행일만 주기 때문입니다.

:::

:::note[참고]

**«지연»은 일정 기준입니다.** 진행 중인데 **예정된 운영 기간이 끝났고 진행률이 100% 미만**인 프로그램입니다. 시스템이 판정해 칸의 수와 카드 배지가 같은 값을 봅니다. 칸을 누르면 지연된 프로그램만 모은 목록으로 갑니다. 시작한 지 며칠 안 된 프로그램은 지연으로 세지 않습니다. **«폐지 프로그램»** 칸은 [프로그램 상세](programs.mdx#종료-승인--재시작--폐지--복원)에서 폐지한 프로그램 수입니다.

:::

## 출석 통계

**주소** `/academic-programs/attendance`

활동별·팀원별 출석률을 봅니다. **출석률 70% 미만**은 눈에 띄게 표시됩니다 — 수료 기준(2/3)에서 온 값이라, 이 아래로 내려간 팀원은 수료가 어려워집니다.

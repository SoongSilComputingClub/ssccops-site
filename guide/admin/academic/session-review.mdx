# 회차 · 출석 승인

**주소** `/academic-programs/reviews/sessions`

스터디장들이 올린 회차 기록을 승인하는 화면입니다. **여러 활동의 제출을 한 화면에** 모아 보여주므로, 활동을 하나씩 들어가지 않고 밀린 것부터 처리할 수 있습니다.

<SessionReviewMock />

| 처리 | 결과 |
|---|---|
| **승인** | 회차가 «승인»으로 확정됩니다. **되돌릴 수 없고**, 승인된 회차는 출석도 고칠 수 없습니다. |
| **수정요청** | 회차가 «수정요청»이 되고 스터디장이 고쳐서 다시 냅니다. **사유가 필수**입니다. |

:::note[주의]

**일괄 승인은 없습니다.** 회차마다 진행 내용과 출석을 확인하고 하나씩 처리합니다. 이미 처리된 회차를 다시 처리하려 하면 «이미 처리됨» 안내가 뜨니 목록을 새로고침하세요.

:::

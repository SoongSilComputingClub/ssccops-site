# RAG 설정 — 도우미가 읽을 문서

**주소** `/ragsettings` · **메뉴** 사이드바 설정 › 규정 도우미 › RAG 설정

[규정 도우미](../account/assistant.md)가 **무엇을 근거로 답할지**를 정하는 화면입니다. 규정 문서를 올리고, 색인이 끝났는지 보고, 어느 문서를 실제 답변에 쓸지 켜고 끕니다.

:::note[주의]

**이 메뉴는 규정 문서 관리 권한자에게만 보입니다**(RAG_DOCUMENT_MANAGE). 목록을 여는 것까지 이 권한이 필요해서, 권한이 없으면 사이드바 **설정** 묶음의 **규정 도우미** 구분 자체가 보이지 않습니다. 도우미에게 묻는 것은 권한이 필요 없다는 점과 다릅니다.

:::

> **화면 예시** RAG 설정 — `/ragsettings`
>
> - 제목 «RAG 설정», 부제 «규정 도우미가 참조할 문서를 등록하고 색인 상태를 관리합니다», 오른쪽 위 버튼 **+ 문서 업로드**
> - 숫자 카드 셋: 등록 문서 4 · 색인 완료 3 · 총 청크 128
> - **지식 문서** 표: 오른쪽 위에 «문서명 검색», 열은 문서명 · 크기 · 청크 · 등록일 · 상태 · 적용 · 조작
>   - «SSCC 회칙(회칙) · 82 KB · 64개 청크 · 2026-03-24 · 색인 완료 · 답변에 사용 중» — 조작: 답변에서 영구 제외 · 재색인 · 삭제
>   - «2026 지원금 집행 지침(일반 문서) · 1.2 MB · — · 2026-09-16 · 색인 중 · 미사용» — 조작: 답변에 사용 · 재색인 · 삭제
> - 표 아래 안내 «올린 문서는 «미사용»으로 등록됩니다. «답변에 사용»을 눌러야 도우미가 그 문서로 답합니다. 개정된 규정을 올릴 때는 옛 문서를 지워주세요. 남겨 두면 옛 조항과 새 조항이 섞여 답합니다.»

## 색인 상태와 적용 상태

**상태**는 문서 색인 진행 상황을, **적용**은 답변에 사용하는지를 나타냅니다. **색인 완료 + 미사용**은 색인은 끝났지만 답변에는 사용하지 않는 문서입니다.

| 상태 (색인) | 뜻 |
|---|---|
| 대기 | 차례를 기다립니다. 곧 읽기 시작합니다. |
| 색인 중 | 문서를 색인 중입니다. 화면이 몇 초마다 상태를 자동으로 확인합니다. |
| 색인 완료 | 다 읽었습니다. 이제 «답변에 사용»을 누를 수 있습니다. |
| 실패 ⓘ | 읽지 못했습니다. **ⓘ에 마우스를 올리면 이유**가 나옵니다 — 대개 파일이 깨졌거나 형식이 맞지 않습니다. |

| 적용 | 뜻 |
|---|---|
| 미사용 | 올라와 있지만 답변에 쓰이지 않습니다. 올린 직후가 이 상태입니다. |
| 답변에 사용 중 | 도우미가 이 문서로 답합니다. |
| 제외됨 | 답변에서 영구 제외한 문서입니다. **되돌릴 수 없습니다.** 다시 쓰려면 같은 파일을 새로 올려야 합니다. |

## 문서를 올리는 순서

1. 오른쪽 위 **+ 문서 업로드**\
   «규정 문서 올리기» 창이 열립니다.
2. 파일을 **끌어다 놓거나 눌러서 고른다**\
   .md · .pdf · .docx, 최대 10MB. 그 밖의 파일은 고르는 순간 막힙니다.
3. **표시명**을 적는다(선택)\
   비우면 파일 이름을 그대로 씁니다.
4. **올리기**\
   «미사용 · 대기»로 들어오고, 잠시 뒤 색인이 시작됩니다.
5. 색인 완료를 기다렸다가 **답변에 사용**\
   이걸 눌러야 도우미가 그 문서로 답하기 시작합니다.

:::note[참고]

**색인 중에 화면을 계속 보고 있을 필요는 없습니다.** 진행 중인 문서가 있으면 화면이 몇 초마다 상태를 자동으로 확인합니다. 색인이 끝나면 확인도 중지됩니다.

:::

## 개정판을 올릴 때 — 옛 문서를 꼭 지웁니다

:::note[주의]

**새 규정을 올리기만 하고 옛 문서를 두면 둘이 섞여 답합니다.** 도우미는 답변에 쓰이는 문서를 전부 근거로 삼기 때문에, 폐지된 조항과 새 조항이 한 답변에 함께 나올 수 있습니다. 개정판을 올렸다면 **옛 문서를 지우거나 «답변에서 영구 제외»하세요**.

:::

## 세 가지 조작

| 버튼 | 하는 일 |
|---|---|
| 답변에 사용 | 이 문서로 답하기 시작합니다. **색인이 끝나야** 누를 수 있습니다. 확인을 한 번 받습니다. |
| 답변에서 영구 제외 | 답변 근거에서 빼고 색인된 내용도 지웁니다. **되돌릴 수 없습니다** — 확인을 받습니다. |
| 재색인 | 문서를 다시 읽습니다. 되돌릴 것이 없어 **확인 없이 바로** 실행됩니다. |
| 삭제 | 문서·색인·원본 파일이 함께 사라집니다. 지금 답변에 쓰이는 문서면 경고 문구가 달라집니다. 되살리려면 같은 파일을 다시 올려야 합니다. |

## 위 카드 셋과 표의 숫자가 다를 때

맨 위 **등록 문서 · 색인 완료 · 총 청크**는 언제나 **전체 문서**를 셉니다. 검색어를 넣거나 «미사용만 보는 중» 같은 필터를 걸면 표의 행 수만 줄고 카드 숫자는 그대로입니다. 잘못 센 것이 아닙니다.

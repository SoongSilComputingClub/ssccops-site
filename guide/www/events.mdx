**주소** `/` · `/events/{eventId}` · 로그인 없이 열립니다

:::note[참고]

**대표 이미지가 없는 행사는 카드가 글자만으로 짧아집니다.** 위 화면 예시의 오른쪽 카드처럼 이미지 영역 자체가 그려지지 않습니다. 장소가 없으면 일시만, 일시가 없으면 장소만 나옵니다 — 없는 값을 «미정» 같은 문구로 채우지 않습니다.

:::

## 배지 두 줄의 뜻

카드와 상세에는 배지가 **최대 둘** 표시됩니다. 앞은 **모집 상태**(신청을 받는가), 뒤는 **행사 진행**(행사 자체가 언제인가)입니다. 두 상태는 각각 계산되므로 행사가 아직 «예정»인데 모집은 이미 «마감»일 수 있습니다.

| 모집 상태 | 뜻 |
|---|---|
| 모집 준비 중 | 운영진이 아직 신청서를 열지 않았습니다 |
| 모집 예정 | 모집 시작일이 아직 오지 않았습니다 |
| **모집 중** | 지금 신청할 수 있습니다 — 이때만 «신청하기»가 눌립니다 |
| 모집 기간 종료 | 모집 기간이 지났습니다 |
| 모집 마감 | 운영진이 모집을 닫았습니다 |

| 행사 진행 | 뜻 |
|---|---|
| 예정 | 행사일이 아직 오지 않았습니다 |
| 진행 중 | 행사 기간 안입니다 |
| 종료 | 행사가 끝났습니다 |

## 학술 프로그램이면 «첨부 자료»가 붙습니다

[학술](site.mdx) 축의 모집 목록에서 스터디 · 프로젝트 · 트랙을 누르면 이 상세 화면이 열립니다. 학술 프로그램이면 본문 카드 아래에 **«첨부 자료»** 절이 붙어, 스터디장이 기획안과 함께 낸 파일이 나옵니다. 지원하기 전에 커리큘럼 상세나 준비물 같은 자료를 내려받아 보는 자리입니다.

- **로그인하고 가입을 마친 회원에게만 보입니다.** 로그인하지 않았거나 가입을 마치지 않았으면 절이 통째로 없습니다. 첨부가 있는지도 보이지 않습니다
- 첨부 자료가 하나도 없는 프로그램에도 절이 없습니다
- 절 머리에 «기획안과 함께 낸 자료입니다.»가 적혀 있고, 줄마다 파일 이름, 크기, 올린 시각과 **내려받기**가 있습니다. 누르면 파일을 받고, 화면 안에서 열어 보는 미리보기는 없습니다

행사 목록과 상세, 신청 패널은 지금처럼 로그인 없이 열립니다. 첨부 자료 절만 회원에게 보입니다. 파일을 올리는 법은 [기획안 제출 · 재제출](../lms/proposals.mdx#첨부-자료-붙이기)에 있습니다.

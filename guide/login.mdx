# 로그인

**주소** `/login`

운영관리시스템은 별도의 아이디·비밀번호를 만들지 않습니다. 소속 Google 계정으로 로그인하면 그 계정이 그대로 회원 식별에 쓰입니다. 처음 로그인하는 사람은 자동으로 **임시회원** 등급으로 시작하고, 이후 운영진이 등급을 조정합니다.

<LoginMock />

## 로그인하는 순서

1. **Google로 계속하기** 버튼을 누른다\
   Google 로그인 창으로 이동합니다.
2. **소속 Google 계정을 선택**한다\
   개인 계정이 아니라 동아리 활동에 쓰는 계정으로 로그인해야 회원 정보와 연결됩니다.
3. 권한 동의 후 자동으로 **운영관리시스템으로 돌아온다**\
   처음 로그인이면 임시회원으로 등록되고, 이미 등록된 사람이면 바로 대시보드로 이동합니다.

:::note[주의]

**로그인이 계속 풀린다면** 다시 로그인해보세요. 같은 문제가 반복되면 운영진에게 등급·권한 확인을 요청하세요.

:::

## 지금 어느 쪽에 들어와 있나 — 실서비스와 테스트

같은 화면을 **실서비스**와 **테스트**(dev)에서 각각 운영합니다. 주소를 잘못 눌러 테스트 쪽에서 작업하면 실제 운영 자료에는 아무것도 남지 않으므로, 헷갈릴 때는 아래 표식을 보세요.

| 볼 곳 | 실서비스 | 테스트 |
|---|---|---|
| 브라우저 탭 제목 | **SSCC 운영관리** | 앞에 `[DEV]`가 붙어 **[DEV] SSCC 운영관리** |
| 탭 아이콘 · 화면 속 마크 | 앱 색 그대로 | 오른쪽 아래 모서리에 **주황색 D** 표식이 붙습니다 |

세 앱은 아이콘 색도 다릅니다. **운영관리**(admin)는 보라·빨강·주황 그라데이션, **공개 웹사이트**(www)는 진회색, **학술 앱**(lms)은 남색·청록입니다. 탭을 여럿 띄워 두고 오갈 때 이 색으로 구분하면 빠릅니다.

# AI 클라이언트 연결

Claude · Codex · Antigravity에서 운영 업무를 대화로 — 운영진용

쓰던 AI 클라이언트에 **운영 시스템을 연결**하면, 화면을 열지 않고 대화로 물어보고 처리할 수 있습니다. "이번 주 마감인 하위 업무 뭐 있어?", "부스 배치도 확정 완료 승인 요청해 줘"처럼 말하면 클라이언트가 시스템을 직접 부릅니다.

:::note[참고]

**운영진을 위한 기능입니다.** 연결한 사람의 권한 그대로 동작하므로, 화면에서 못 하는 일은 여기서도 안 됩니다. 부원에게 안내할 기능이 아닙니다.

:::

## 이렇게 말하면 됩니다

정확한 명령어가 아니라 **무엇을 원하는지**를 말합니다. 클라이언트가 필요한 값을 되묻거나 현황을 먼저 읽고 채웁니다. 아래는 실제로 되는 문장들입니다.

| 하고 싶은 일 | 이렇게 |
|---|---|
| 현황 보기 | "지금 내가 처리해야 할 게 뭐야?" → 대시보드 · "이번 주 마감인 하위 업무 보여 줘" · "홍보국 업무 중 지연된 거 있어?" |
| 업무 만들기 | "다음 주 개강총회 준비 업무 만들어 줘. 담당은 나, 마감은 다음 금요일" → 없는 값은 되묻습니다 |
| 지난 것 참고 | "작년 MT 업무 찾아서 같은 구성으로 올해 MT 업무 만들어 줘" → 목록을 읽고 제목·유형·점검 항목을 옮겨 옵니다 |
| 상태 넘기기 | "부스 배치도 확정 건 완료 승인 요청해 줘" · "○○ 하위 업무 반려해 줘, 사유는 '예산안 첨부 빠짐'" |
| 회의 | "내일 저녁 8시 국장단 회의 잡아 줘. 안건은 홈커밍 예산이랑 모집 일정" · "지난 회의 안건 중 처리 안 된 거 알려 줘" |
| 행사 | "10월 첫째 주 토요일 가을 MT 행사 초안 만들어 줘, 장소 강촌, 정원 40명" → 초안으로 생기고 공개는 따로 "공개해 줘" |
| 모집 | "접수 중인 폼 뭐 있어?" · "44기 지원서 접수 닫아 줘" |
| 홍보 사이트 | "핵심 가치 페이지에 '나눔' 카드 하나 더 넣어 줘" · "어제 세미나 포스트 게시해 줘" |

## 바꾸거나 지울 때 주의

| 상황 | 알아 둘 것 |
|---|---|
| 수정 | "제목만 바꿔 줘"라고 하면 제목만 바뀝니다. 다만 **같은 시각에 다른 사람이 화면에서 고치고 있었다면 그 사람의 변경을 덮습니다** — 여럿이 만지는 건은 먼저 읽고("지금 어떻게 돼 있어?") 바꾸세요. |
| 비우기 | 값을 **비우는** 것(장소 지우기, 폼 연결 끊기)은 대화로 되지 않습니다. 화면에서 하세요. |
| 상태 넘기기 | 허용되지 않는 순서(검토 중인 것을 다시 착수 등)는 시스템이 거절하고 이유를 돌려줍니다. 되돌리기는 화면과 같은 규칙입니다. |
| 공개·게시 | 행사 공개와 콘텐츠 게시는 **바로 외부 사이트에 나옵니다**(최대 5분 뒤). 초안 상태에서 내용을 확인한 뒤 공개하세요. |
| 지우기 | **폼과 행사만** 대화로 지워집니다. 지운 것은 «되살려 줘»로 돌아옵니다. 그 밖의 것은 "지워 줘"라고 해도 도구가 없습니다. |
| 기록 | 모든 조작은 화면에서 한 것과 같이 남고, AI에서 했다는 표시가 붙습니다. 점검 목록 변경은 하위 업무 상세의 «변경 이력»에 보입니다. |

## 연결하는 법

붙일 주소는 어디서나 같습니다 — `https://api.sscc-ssu.com/mcp`. 처음 붙일 때 **브라우저가 열리고 구글 로그인과 허용 화면**을 지납니다(아래). 기능은 v0.2.9에 들어왔고 **실서비스에서 실제로 붙을 수 있게 된 것은 v0.2.10부터**입니다.

| 클라이언트 | 하는 법 |
|---|---|
| Claude<br />(claude.ai · 데스크톱 앱) | 설정 → **커넥터** → **사용자 지정 커넥터 추가**에 위 주소를 넣습니다. 요금제에 따라 이 메뉴가 없을 수 있습니다 — 그때는 Claude Code를 쓰세요. |
| Claude Code | `claude mcp add --transport http ssccops https://api.sscc-ssu.com/mcp` → 세션에서 `/mcp` → **Authenticate**. |
| Codex CLI | `codex mcp add ssccops --url https://api.sscc-ssu.com/mcp` → `codex mcp login ssccops`. |
| Antigravity | 에이전트 패널 → **MCP Servers** → 서버 추가에 위 주소를 넣고 로그인을 누릅니다. 설정 파일을 직접 고친다면 `~/.gemini/antigravity/mcp_config.json`의 `mcpServers`에 `{"ssccops": {"serverUrl": "https://api.sscc-ssu.com/mcp"}}`. |
| Gemini CLI | `gemini mcp add -t http ssccops https://api.sscc-ssu.com/mcp` → 세션에서 `/mcp auth ssccops`. |

## 처음 한 번 — 허용 화면

연결을 시작하면 브라우저에 **운영 시스템 로그인**이 뜨고, 로그인하면 그 앱이 무엇을 요청하는지 보여 주는 화면이 나옵니다. 여기서 **허용**을 눌러야 연결이 끝납니다 — 그 화면을 읽는 법은 [외부 앱 접근 승인](../account/oauth-consent.mdx)에 있습니다. **앱 이름과 돌아갈 곳이 기대한 것과 다르면 거절하세요.**

## 알아 둘 것

| 항목 | 내용 |
|---|---|
| 권한 | 연결한 본인의 권한 그대로입니다 — 업무는 업무 관리, 회의는 회의 관리, 행사는 행사 관리, 폼 접수는 폼 상태 변경, 콘텐츠는 콘텐츠 관리 권한이 각각 필요하고 화면과 같은 이름입니다. 권한이 없으면 "권한이 없습니다"로 끝나며, 대화로 조른다고 열리지 않습니다. 어떤 권한이 있는지는 "내 권한 알려 줘"로 봅니다. |
| 기록 | 상태 변경 같은 조작은 **화면에서 한 것과 똑같이 기록**에 남습니다. 기록에는 그 일을 화면에서 했는지 AI에서 했는지도 함께 남습니다. |
| 확인 | 바꾸는 일은 클라이언트가 **실행 전에 물어봅니다**. 무엇을 바꾸는지 읽고 누르세요 — 습관적으로 넘기면 원치 않은 변경이 들어갑니다. |
| 개인정보 | 회원 **이름**은 오가지만 **연락처·이메일·학번은 나가지 않습니다.** 대화 내용은 각 AI 업체 서버에 남으므로, 대화를 외부에 공유할 때는 명단이 섞여 있지 않은지 보세요. |
| 연결 끊기 | 클라이언트의 커넥터·MCP 목록에서 지우면 됩니다. |

## 잘 안 될 때

| 증상 | 보는 곳 |
|---|---|
| "가입이 필요합니다" | 운영 시스템에 아직 가입하지 않은 계정입니다. 웹에서 먼저 가입하세요. |
| "권한이 없습니다" | 내 권한으로 막힌 것입니다. **내 계정**에게 물어 어떤 권한이 있는지 확인하고, 필요하면 운영진에게 권한을 요청하세요. |
| 도구 목록이 옛날 그대로 | 도구 목록은 **연결할 때 한 번** 가져옵니다. 기능이 늘었는데 안 보이면 연결을 끊었다 다시 붙이세요. |
| 로그인 창이 안 뜬다 | 브라우저가 기본 브라우저로 열리는지 확인하고, 그래도 안 되면 클라이언트를 껐다 켜고 다시 시도하세요. |

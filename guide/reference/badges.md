# 배지 · 표기 범례

화면 전반에서 반복되는 시각 표기

## 상태 배지 톤

| 배지 색 | 쓰는 상태 |
|---|---|
| 파랑 | 진행 · 승인 · 접수중 |
| 주황 | 대기 · 검토 |
| 빨강 | 지연 · 반려 · 미연결 |
| 회색 | 완료 · 중립 |
| 테두리만 | 기본 상태 |
| 파란 테두리 | 강조 필요 |

## 마감 표기

| 배지 | 의미 |
|---|---|
| D-3, D-1 … | 마감까지 남은 일수 |
| D-DAY | 오늘이 마감일 — 아직 지연은 아닙니다 |
| D+2 · 지연 | 마감을 넘긴 상태. 빨간 글자·배지로 표시됩니다 |
| 마감임박 | 마감 3일 이내 |

## 목록을 넘기는 두 가지 방식

목록에는 **페이지 번호로 바로 이동하는 기능이 없습니다.** 화면에 따라 둘 중 하나입니다. 업무·하위 업무·승인함처럼 **더 보기** 버튼으로 다음 항목을 아래에 추가하는 곳과, **회원 목록**처럼 한 번에 한 쪽씩 **이전·다음**으로 옮기는 곳입니다.

| 방식 | 쓰는 곳과 특징 |
|---|---|
| 더 보기 | 누를 때마다 다음 항목이 아래에 추가됩니다. 업무·하위 업무·승인함·폼·행사 등 대부분의 목록에서 사용합니다. |
| ◀ 이전 · 다음 ▶ | **회원 목록**입니다. 한 번에 한 쪽만 보이고 가운데에 **21–40 / 전체 137명**처럼 지금 위치가 적힙니다. 검색어·등급·상태·정렬과 현재 쪽이 주소에 담겨 있어, 상세에 다녀오거나 새로고침해도 **보던 자리로 돌아옵니다**. 페이지 번호를 눌러 뛰는 기능은 없습니다. |

# 공유 링크

화면 오른쪽 위 **공유하기** 버튼 — 메신저로 보낼 링크

업무·회의·활동처럼 **주소를 그대로 복사해 보내면 상대가 열지 못하는** 화면들이 있습니다. 이런 화면은 공유 버튼으로 **전용 링크**를 만들 수 있습니다. 카카오톡·디스코드에 붙여 넣으면 제목과 요약이 담긴 카드로 보이고, 누른 사람은 해당 화면으로 곧장 이동합니다.

| 공유할 수 있는 것 | 누가 받는가 | 버튼이 있는 자리 |
|---|---|---|
| 업무 | 운영진 | 업무 상세 |
| 하위 업무 | 운영진 | 하위 업무 상세 |
| 회의 | 운영진 | 회의 상세 |
| 스터디 · 프로젝트 · 트랙 | 부원 · 지원자 | 활동 상세(학술 앱) |
| 회차 | 부원 | 회차 상세(학술 앱) |
| 행사 | 누구나 | 행사 상세 |

:::note[참고]

**공유 대상에 따라 연결되는 앱이 다릅니다.** 업무·하위 업무·회의 링크는 **운영관리**로, 스터디·회차·행사 링크는 **공개 웹사이트**로 연결됩니다.

:::

## 공유 상태별 버튼

| 버튼 | 누르면 |
|---|---|
| 공유하기 | 아직 링크가 없는 상태입니다. 누르면 링크가 만들어지고 곧바로 복사됩니다. |
| 링크 복사 | 이미 만들어 둔 링크가 있습니다. 누르면 같은 링크를 다시 복사합니다 — **누를 때마다 새 링크가 생기지 않습니다.** |
| 공유 중지 | 그 링크를 폐기합니다. 이미 보낸 링크도 즉시 열리지 않게 됩니다. |

**링크에는 만료 기간이 없습니다.** 한 번 만들면 **공유 중지**를 누르기 전까지 계속 사용할 수 있습니다. 더 이상 공유하지 않으려면 직접 중지해야 합니다.

:::note[주의]

**링크를 받았다고 내용까지 보이는 것은 아닙니다.** 링크가 보장하는 것은 **제목과 요약이 담긴 카드까지**이고, 실제 내용은 이동한 뒤 **로그인과 권한 검사를 지나야** 보입니다. **권한 없는 사람은 링크를 받아도 내용을 볼 수 없습니다.**

:::

## 행사만 규칙이 다릅니다

행사는 **게시 여부에 따라 공유되는 링크가 다릅니다.** 운영진이 링크 종류를 따로 고를 필요는 없으며, 버튼 옆 안내에서 공유될 링크를 확인할 수 있습니다.

| 행사 상태 | 공유되는 링크 |
|---|---|
| 작성 중 | 전용 링크입니다. 아직 공개하지 않은 행사를 나눌 유일한 방법이며, 받은 사람에게는 **제목과 요약만** 보입니다. |
| 게시 | 누구나 여는 **공개 주소**입니다 — 이미 공개된 행사라 전용 링크를 따로 만들지 않습니다. |
| 보관 | 새로 공유할 수 없습니다. 게시 전에 만든 링크가 남아 있으면 중지만 할 수 있습니다. |

**게시 전 링크를 행사 안내로 쓰면 안 됩니다.** 그 링크는 제목과 요약까지만 열리므로, 받은 사람은 안내를 받은 줄 알고 본문을 보지 못합니다. 본문까지 보여 주려면 행사를 먼저 **게시**한 뒤 공개 주소를 보내야 합니다.

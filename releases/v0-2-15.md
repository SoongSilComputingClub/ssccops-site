수정 요청을 받은 응답을 다시 내지 못하던 문제를 고쳤습니다. 함께 알림과 푸시, 홈 화면에 추가가 들어갔습니다.

## 달라진 것

### 수정 요청받은 폼 응답을 다시 낼 수 있습니다

공개 웹사이트에서 수정 요청을 받은 폼 응답을 고쳐 다시 내려고 하면 제출이 되지 않던 것을 고쳤습니다.

### «내 활동» 맨 위에 «다시 제출할 것»

신청한 행사, 낸 폼, 기획안 가운데 수정 요청을 받은 것이 «내 활동» 맨 위에 모입니다. 카드 색이 달라 눈에 띄고, «다시 제출하기 →»로 바로 고치러 갑니다. 목록에서도 수정 요청은 «제출됨»과 따로 보입니다.

### 알림과 푸시

상단 바에 종이 생겼습니다. 다음 일이 생기면 알림이 쌓입니다.

- 하위 업무 검토 요청은 결재할 사람에게, 승인과 반려는 담당자에게 갑니다.
- 마감 하루 전과 마감이 지났을 때 담당자에게 매일 아침 9시에 갑니다.
- 폼 응답 승인, 반려, 수정 요청은 응답한 사람에게 갑니다.
- 행사 참가 확정, 대기, 취소는 신청한 사람에게 갑니다.

푸시를 켜 두면 앱을 열어 두지 않아도 기기로 알림이 옵니다. «테스트 알림 보내기»로 잘 오는지 확인할 수 있습니다. 공개 웹사이트에 다시 들른 분에게는 «홈 화면에 추가» 안내 띠가 보입니다.

자세한 내용은 [알림, 푸시, 홈 화면에 추가](/guide/account/notifications) 설명서에 있습니다.

### 계정 메뉴 하나로

세 앱 모두 내 정보, 테마, 다른 앱, 홈 화면에 추가, 로그아웃을 계정 메뉴 하나에 모았습니다. 상단 바에는 알림 종만 남습니다.

### 검색 결과와 링크 카드

공개 웹사이트가 검색 결과와 링크 카드에 제대로 나오도록 손봤습니다. 관리자 페이지와 학술 앱은 검색 결과에 나오지 않게 했습니다.

## 해 주실 일

- 알림을 기기로 받고 싶으시면 계정 메뉴의 알림 설정에서 푸시를 켜 주세요. 푸시는 기기마다 따로 켭니다.

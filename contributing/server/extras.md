## 담을 내용

- MCP: 서버 안에서 `/mcp`로 열리고, 도구가 자기 REST를 호출하며, Supabase OAuth를 그대로 쓴다. 삭제 도구는 되살리는 API가 있을 때만
- 규정 도우미(RAG): Spring AI, pgvector, Gemini, 기본으로 꺼져 있는 플래그
- 알림과 웹 푸시: VAPID 직접 구현, 수신 앱은 기준표가 정한다
- 감사 로그: 테이블 대신 ECS JSON 로그로 남긴다(로그 저장소 구성은 쓰지 않는다)
